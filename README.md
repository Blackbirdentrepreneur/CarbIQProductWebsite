# Glycemix – AI Diabetes Companion

A site for the **Glycemix mobile app** — a smart diabetes and prediabetes management tool powered by AI. This React + Tailwind CSS site is built to drive downloads and educate users on the app's powerful features.

---

## Key Features

- **Instant Food Scanning** – Snap a photo, get blood sugar predictions and carb counts.
- **AI-Driven Insights** – Personalized suggestions to manage blood sugar levels.
- **Progress Tracking** – View active minutes, foods scanned, and glucose levels.
- **Testimonials** – Trusted by patients and healthcare professionals.
- **Transparent Pricing** – Free trial + affordable plans.
- **Privacy & Legal Info** – Fully detailed terms and privacy policy.
- **Contact Form** – Let users reach out directly for support or inquiries.

---

## Tech Stack

- **Framework**: React (with TypeScript or JavaScript)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React Icons
- **Hosting Ready**: Vercel, Netlify, Firebase, etc.

## Getting Started

Clone and run locally.

### 1. Clone the Repository and Enter Directory

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm run dev
```

> For **Vite**, use `npm run dev`.  
> For **Create React App**, use `npm start`.

---

## Production Build

```bash
npm run build
```
